# 交接记录需求追踪

本文档将 `指套管信息/指套管相关知识/交接记录.txt` 转为可验收的产品规则，避免导入、可视化和报告逻辑再次漂移。

## 已实现

- 50 根指套管按外部编号 1-50 管理；奇数机组使用奇数映射，偶数机组使用偶数映射。
- 导入流程分为文件夹解析生成标准 Excel、选择最终 RPT 版本、Excel 入库三步；候选版本按数据组隔离，支持机组/大修/分析人员筛选。
- RPT、ECT、SUM 分层保存；重复导入幂等；无效指示、NDD 与标定文件不计入缺陷高亮。
- 工作台勾选记录与二维管板、三维模型同步；未勾选时管板全部白色，勾选后按同一管最大磨损比例显示单一严重度颜色。
- 管状态维护支持正常、堵管、换管、位移和位移量；历史对比支持 R/NI、任意两次大修、堵管停止和换管重置基准。
- 结果报告与历次对比报告均可预览并导出 Word，由现场人员另存 PDF。
- 当前勾选范围可导出二维管板 PNG，并显示缺陷管数量、最大磨损和 P 区密集度统计。

## 待现场确认

- 管板高清图纸中的编号-坐标映射，尤其交接记录指出的异常编号；在确认前不得猜测或自动修正。
- 堵管、换管、位移清单的正式字段、单位和生效大修号。
- P1-P5（软件保留 P6 结构层）在三维模型中的实际高度定义。
- 历次演变三维时间轴的展示层级和报告模板字段。

## 验收规则

1. 同一机组才允许多选并生成结果报告；跨机组勾选必须提示并阻止。
2. 同一数据组存在多个 RPT 时必须人工选一份，不能批量导入全部版本。
3. `R` 只表示位置匹配到旧缺陷，`NI` 表示旧位置不存在或换管后的新基准；原始显示位置不可被位移量改写。
4. 未勾选记录时二维管板不得自动着色；点击管位仍可查看当前筛选下的详细记录。
5. 报告字段未知时保留空白，不从文件名或历史绝对路径猜测。
