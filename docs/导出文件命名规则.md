# 导出文件命名规则

软件生成的用户文件统一使用以下结构：

```text
TH_<文件类型>_<业务范围>_<本地日期时间>_<随机码>.<扩展名>
```

- `TH`：本软件生成的文件标识。
- `文件类型`：结果报告、历次大修对比报告、管状态维护、数据质量清单、管板缺陷分布等。
- `业务范围`：包含可识别的大修号、机组号、批次号或全库范围；长范围会安全截短。
- `本地日期时间`：`YYYYMMDD-HHMMSS-mmm`，使用运行软件的 Windows 本地时间。
- `随机码`：12 位十六进制随机标识，避免短时间重复导出互相覆盖。
- `扩展名`：小写格式，如 `docx`、`xlsx`、`csv`、`png`、`json`、`db`、`bak`。

示例：

```text
TH_检验结果报告_机组1_N108_20261023-143015-042_42a8d31f09ce.docx
TH_检验报告单_机组1_F101_20261023-143015-043_b741b0e513c2.csv
TH_管状态维护_机组1_F102_20261023-143016-105_5c247ae195ba.xlsx
TH_管板缺陷分布_D118-机组1_20261023-143017-210_f7a11c2de423.png
TH_数据库备份_manual_20261023-143018-001_884c418a0b26.db
```

范围字符串会替换 Windows 文件名非法字符，并限制长度。检测/报告导出、维护状态导出、质量清单和数据库备份由软件分别放入对应输出目录；管板图片和报告表头设置在保存对话框中使用相同命名结构，可由用户选择实际保存位置。

报告中心按实际表式使用“检验报告单”“检验结果比对表”；遗留结果报告导出入口的类型仍为“检验结果报告”。不同入口均使用上述唯一命名结构。
