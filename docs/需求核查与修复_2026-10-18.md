# 本地软件需求核查与修复

核查依据：用户当前要求、`记忆/记忆导出/我的输入信息.txt`、项目记忆需求基线。资料中的历史方案与推断不作为新增业务判据。

## 本轮落实

| 需求 | 实现 |
| --- | --- |
| 导入批次可追溯 | 原始目录与 Excel 导入记录操作者、时间、解析器版本、来源、解析/入库/重复/错误数量及状态 |
| 文件校验 | 流式 SHA-256、文件大小、修改时间、类型和解析状态；同一文件可追溯到多个批次 |
| 候选报告保留 | 记录本批次选用与未选用报告，后端拒绝同组同时选多个版本 |
| 异常清单 | 缺失 RPT、无 ReportEntry 的 ECT、关联错误、文件名/HeaderTube 错误、SUM/机组错误、映射错误、重复采集、哈希冲突、三字符缺失、异常表格行 |
| 原始字段保留 | 新导入记录保留逐行原值、工作表和行号；异常行在校验记录中保留，不截断为前 100 行 |
| 批次回滚和恢复 | 新增记录软撤回，三字符修改恢复到修改前；整批事务，检测后续修改冲突；原始文件、管状态、审计保留 |
| 数据质量查看与导出 | 报告与导出内的折叠区域；Excel 导出批次、校验问题、文件校验、报告版本、记录原值 |
| 地图更新 | 再次进入可视化刷新本机统计，回滚至空库后清除旧基地计数；大亚湾与岭澳共享同一地图点 |
| 状态统计 | 按基地、机组、管号区分，不再将不同基地的同号管合并 |
| 误导性标签 | “大修中/运行机组”改为数据实际代表的导入/接入信息；50% 仅作为参考分级 |
| 新旧报告界面冲突 | 清除重复报告模式标签，保留一个正式报告模式入口 |
| 三维性能 | 使用显示器实际 DPI，隐藏三维页时暂停绘制；修正帧率文本 |
| 三维缺失信息 | 无记录不再写成无缺陷；缺少磨损深度的指示不隐藏；无位置不默认放在 P3 |
| 三维定位诚实性 | 保留有符号原始毫米偏移；没有物理标定时按 P 层示意，取消固定 400 mm 比例猜测 |
| 回收站隔离 | 恢复一次删除只恢复对应导入元数据，不恢复其他删除批次 |

## 验证范围

- Python 回归测试覆盖导入事务失败、去重、报告版本选择、完整异常导出、原值追溯、回滚恢复与冲突阻止。
- Electron 使用独立临时数据库运行，不修改正式检测数据。
- 桌面交互覆盖两类报告预览、Excel 输出、审计筛选、批次回滚恢复、空库地图刷新、紧凑窗口和三维画面像素及选管。
- 新增位置解析测试覆盖空位置、错误 P 位、正负毫米偏移与未标定的 P 层示意。
- 本轮 Python 58 项回归通过；38 个 ESM 文件检查通过；Electron 实际窗口交互与三维像素检查通过。

## 仍需核对的边界

- 历史导入没有批次/文件哈希时，界面明确提示；不会编造历史审计。
- 三维 P1–P6 的工程距离与不同机组管长还需要真实物理基准，当前模型为工程示意。
- 既有三个历史趋势/管板图仍使用随软件保存的参考台账，已标注“历史参考台账”；地图和本机汇总使用 SQLite。
- 旧 `.xls`、表格批量/文件夹选择、所有资料模板逐页排版验收尚未在本轮全部完成。
- 本轮更新的是本地软件源码，已有历史安装包不会自动包含这些修改。
