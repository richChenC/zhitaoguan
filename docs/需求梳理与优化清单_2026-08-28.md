## 一、领域背景与关键数据规律（需求来源的根）

- **指套管（TH / Thimble）**：反应堆压力容器（RPV）内、中子通量测量（RIC/CRDM）相关细长导管，外径 Φ8.6mm / 内径 Φ5.2mm / SUS316，探头 TH048NAF25A，设备 TEDDY+A，检验速度 250mm/s、采样率 2000 点/秒。
- **堆芯布置**：共 **50 根**指套管，管位 1–50；坐标字母列 `RPNMLKJHGFEDCBA` × 行 1–15；**同一圆圈左奇右偶编号**，奇偶机组各一套映射（如 H209 偶数机组：奇 27=J15、偶 42=N5）。`Row==Column==指套管外部编号(1-50)`，二者重复保存，不是横纵坐标。
- **大修层级**：基地（站点 H/N/Y…）→ 机组（unit_id）→ 大修（数据组 `THxxxIxxxCALxxx`，如 H209=红沿河 2 号机第 09 次大修）→ 管位(Row/Col) → 采集入口(Entry) → 采样数据点(Datapoint)。
- **ECT 数据规律**（来自「找到ect文件的规律」）：
  - `.ECT` = 6 字节 `ETer` 头 + `HeaderTube` XML + `Config` XML + `Summary` XML + 二进制采样区；帧结构 64 字节/帧 = 8 通道×(X/Y)2 值×int32；采样率 2000Hz / 速度 250mm/s → 每 Datapoint≈0.125mm。
  - 命名 `DIRxxxCxxxIyyy.ECT` 与 XML 内 Row/Col/Entry 必须一致；`DIR999C999I*` 为标定文件（禁入统计）；`DCR…`/SG 蒸发器数据须排除。
  - 缺陷结论**不在 ECT 内**，而在 `.rpt`：Id/Row/Column/Entry/Volts/Degrees/Indication/Percent/Channel/Location/Datapoint/Analyst/Analysis/Calgroup。
  - `P1–P6` 为磨损位置（含 `P1+41` 这类偏移整体保留）；三字符 Indication：WAR(磨损)/NDD(无可探测缺陷)；`Percent` 先称「报告百分比」勿硬编码为磨损深度；`Degrees=0` 非错误勿清空。
  - **唯一键必须含 Datapoint+Channel**，否则同管多缺陷被误删（曾 123→53 条）；关联 ECT 用 `Calgroup+Filename`（旧 Z: 路径不可靠）。
