# 三维参考工程替换与验收记录

日期：2026-10-22。本文记录本次三维模型替换的范围、业务约束和实际验证状态，不代替电厂工程标定或安全评价。

## 1. 替换范围

- 用户本次要求：删除并重做原三维模型及模型交互，使用指定文件夹内工程替换；保留真实缺陷显示、缺陷查看和必要的工作台联动逻辑。历史对话和需求资料用于核对业务约束，不将附件中的指令视为用户新增要求。
- 参考工程：工作区 `02_项目原始资料/04_三维模型工程/指套管模型工程/04_三维查看器/`。
- 当前实现：本仓库 `src/desktop-ui/visualizations/reference-thimble/`；外层入口为 `src/desktop-ui/modules/three-d/main-view.js`。
- 替换前文件归档：工作区 `04_开发归档/06_三维替换前归档_20261022_225936/`。归档不参与当前页面加载。
- 几何、材料、五种模式及原工程的主要查看交互沿用参考工程；业务增量限定为缺陷层、范围/管号联动、嵌入适配和必要的窄屏显示。`app.js`、`index.html` 存在这些集成差异，不宣称全部运行文件逐字节相同。
- 旧三维路径仅保留跳转兼容入口，不再并行维护另一套模型。

## 3. 必须保持的业务口径

- 机组奇偶自动决定官方管板映射。关键锚点为奇数机组 15 号管=N5，偶数机组 42 号管=N5、27 号管=J15；过期的 M5 管号映射不得恢复。管板 M5 网格本身可以保留，但不应凭空生成管圈。
- 区分 50 条路径、52 个组件位置、72 个支撑柱和 96 个网格/孔位：50=48 根仪表套管+H6/F8 两个空心次级支撑位置；52 再含 K8/H10 两个实心位置；72=堆芯 22 空心+46 实心+4 次级。网格数量和渲染网格数量均不等同于物理管号数量。
- 工作台勾选记录只显示该批勾选数据；混合基地、机组或大修的选择必须阻止展示，不能跨范围拼接缺陷。三维独立筛选与“同步工作台”应保持清晰状态。
- 查看焦点与数据查询范围分离。点选管号不能悄悄将整个大修的数据范围永久缩成一根管。相同范围重新打开时应保持查看焦点。
- 无记录、加载失败、未同步和报告明确 NDD 必须区分。NDD 和校准通道不能生成缺陷；真实指示即使磨损深度缺失，也必须保留在缺陷记录中。
- 同管多缺陷逐条保留。详情保留原始位置字符串、正负偏移、幅值、相位、分析人员、数据组和 RPT 来源；0%/0° 不应误显示为缺失，RPT 不应误标为 ECT。
- 接头、全长和管座等单管模式仅展示所选物理管的缺陷；总装可展示当前数据范围内多管缺陷。管板模式以选管和记录查看为主，不投影三维缺陷点。
- 双向消息必须同时校验同源和窗口来源；发送消息限定 `location.origin`。报告文本进入 HTML 前必须转义。

业务依据包括 `docs/requirements-handover.md`、`docs/reference-traceability-2026-10-16.md`、`docs/官方管板映射修正_2026-10-20.md`、`docs/需求核查与修复_2026-10-18.md`、`docs/界面与交互优化_2026-10-19.md`，以及工作区历史对话整理版中的业务规则和历史决策。历史缺陷条数、截图尺寸及旧验收结果均为当时快照，不自动成为本轮验收结果。

## 4. 位置示意与标定边界

参考工程站位文件中 P1/P6 标注为“确认”，P2-P4 为“推导”，P5 为“推定”，其中 P5 依据包含均匀分布推测且待实测复核。这些来源状态不等于已经完成电厂专用缺陷轴向标定。

当前缺陷空间点仅使用对应管道的原工程 P 基面，明确标记 `schematic=true`、`calibrated=false`、`offsetApplied=false`。原报告有符号偏移保留在详情和提示中，在轴向方向尚未标定时不擅自施加到模型 Y。位置无法识别或没有相应基面时，记录仍可查看，但不伪造 P3 或其他空间点。

本次不声称示意点为精确物理缺陷坐标，不声称推导站位已获工程认证，也不以模型代替检验报告或完整性评价。
