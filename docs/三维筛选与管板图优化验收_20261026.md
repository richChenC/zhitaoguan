# 三维筛选与管板图优化

日期：2026-10-26。代码位于 `软件正式版_20261021`，不重新制作安装包。

## 本次行为

- “默认视角”和左键双击使用同一复位逻辑：恢复初始整体轴测、屏幕居中、部件显隐，关闭剖切、爆炸、自动旋转和顶部管板图，收起设置与详情。已选择的数据库范围和管号保留。
- 检测筛选包含独立的基地、机组、大修三级联动。未选择或范围不完整不渲染缺陷；完整范围读取全部分页，显示整批缺陷。
- 更换基地/机组会立即清除旧缺陷；清空和查询失败也会移除三维网格与点击标记，不保留上一批的错误画面。
- 自选数据库范围不被工作台返回或管号焦点消息覆盖。记录点击、管号输入与滑动只改变焦点，不缩小整批查询或自动切到整管模式。
- 缺陷为三维场景网格，点击目标随相机投影更新。磨损百分比改变显示符号尺寸，不代表真实缺陷表面积、体积或周向角。
- 相邻缺陷保持各自的轴向坐标；点击范围重叠时合并可查看的记录，防止近邻点互相遮挡。
- 当前管身采用醒目的琥珀色贯穿高亮，管板孔位同时描边；状态色和当前选中状态分开处理。
- 顶部管板使用原始 `plate_plan.svg` 的169个栅格、50个孔位、行列标记和方向箭头生成透明三维图层。装配模式下任意视角、旋转和缩放都可开关，不再限定俯视。
- 管板开关在所有视图均可点击；从整管、接口或图纸视图打开时，切回完整装配并叠加管板。按钮显示的是当前画面的实际开关状态，不在隐藏图层时仍显示“开”。
- 俯视按原图 R→A、180°上方、0°下方的方向展示；投影转换不改动原模型坐标或 CAD 数据。XYZ 轴标和中键平移同步适配。
- 有机组选择时只显示相应奇偶编号；同一 N5 孔位，奇数机组15号、偶数机组42号。未选机组时显示双编号。
- 管板加载失败有提示，开关回到关闭状态，支持重试；纹理使用当前软件允许的本地数据格式，未放宽资源安全策略。
- 检测筛选、管子详情和模型设置互斥展开，窗口宽高受约束。整管标尺与详情/筛选互斥，刻度按面板实际高度定位。快速管号导航保持可用。

## 定位口径

模型参考轴向：正值从 P1 指向 P6，模型 Y 相反。

`模型 Y = 所属 P 基面 Y - 报告带符号偏移 - 明确的同次大修维护移位量`

维护修正显示“维护后示意”，同时保留报告位置、移位距离、维护原文和来源。只应用明确的正负距离，不把无方向的“割管50 mm”擅自当成正向移位，也不累计历次维护。

参考基面来源状态保留：P1/P6来源确认，P2-P4推导、P5推定。源工程模型轴向不等于电厂实测标定；正式标定和维护生效口径仍需现场确认。报告与数据库原始位置不改写。
