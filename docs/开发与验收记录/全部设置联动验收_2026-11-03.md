本轮按当前设置窗口逐项核对消费者、跨窗口通知、实际显示和重启持久化。只修改当前软件正式版，没有打包，登录及桌面继续使用现有 TH 图标；右上角设置按钮仍为导航工具区最后一项，设置仍在独立窗口打开。

这些显示阈值只用于可视化和分析，不作为维修或验收判据。数据库校验、备份恢复、去重和审计是操作入口，继续按原本权限执行。当前数据库仍为本地 SQLite，检测来源目录不启用预留的远程服务配置。

本机桌面偏好与数据库设置的保存范围不同：复制或恢复数据库不会迁移所有界面偏好。恢复数据库时，账户及安全信息、当前备份策略按照既有恢复保护机制处理，具体见本地正式版备份与权限实现。

## 本轮修正

- 增加 `settings-sync.js`，统一严重度的读取、校验和 CSS 变量；使用不含凭据或草稿的本机更新通知，使其他窗口重新读取服务端权威值。
- 增加 `settings-runtime.css`，修复密度样式被覆盖、无缺陷颜色被固定白色覆盖，以及三维 iframe 未统一减少动画的问题。
- 统一 Report 三处入口；运行中的扫描或导入延后应用策略，保留本次任务的选择。
- 来源配置在加载、保存或校验期间收到更新时排队重读，避免丢失更新；不覆盖草稿和用户另选的导入路径。
- 所有相关严重度界面使用共同设置；补齐趋势数值标注刷新，更新颜色时保留完整管板及已选记录。
- 通知改为重新读取时长，允许切换“不自动隐藏”后取消当前通知的旧计时器。
- 删除三维入口的一次重复刷新，避免切回模型时中断第一次请求并暂时清空数据。
- 更新偏好页说明，准确区分本机界面偏好与数据库保存的移位设置。

旧 `modules/analytics/ledger.js`、`chart-3-2.js` 没有被当前入口导入；当前可视化入口为 `official-workspace.js`。本轮没有把旧文件中的业务汇总阈值机械替换为显示设置，也没有修改业务源数据或已导出报表。
