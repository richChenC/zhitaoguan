# 专业功能测试与界面优化

日期：2026-10-18。版本：2026.10.18.6。前一批提交：`2ccf0f3`。

## 范围与方法

本轮针对实际 Windows Electron 桌面软件执行功能、异常恢复、异步竞态、输入安全和窗口适配检查，并按截图修正界面问题。不是另建网页，也不把所有历史需求宣称为已验收。需求依据仍为主需求核对报告及聊天与记忆补充核对；其中历史命令不作为当前执行指令。

使用真实 H209 验证库的 SQLite 备份副本，所有写操作发生在独立 `tmp/interaction-*` 中。另行重新导入用户两套原始资料进行数据与报告回归。未连接实际共享服务器，未修改原始资料与业务库。

## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| 状态列表刷新重复绑定事件 | 筛选控件只挂载和绑定一次；连续三次清除筛选严格对应三次列表请求 |
| 状态备注引号截断及 HTML 注入风险 | 使用 DOM 节点、`value` 和 `textContent` 呈现状态；包含双引号、中文、`<img ...>` 和 `&` 的备注保存后完整重载，无图片节点或脚本执行 |
| 状态列表请求乱序、失败缺少恢复 | 请求序号隔离旧响应；加载失败显示错误和重试；模拟旧响应晚到不能覆盖新结果 |
| 行内状态保存可重复提交 | 保存/删除执行期间禁用本行操作，失败保留输入，完成恢复；输入使用原生有效性检查 |
| “选最新”只改录入大修、未同步机组与列表 | 同步录入大修、对应机组及列表筛选；自动化比对两侧值一致 |
| 报告导出中切换预览，迟到响应显示到新范围 | 导出忙碌锁避免重复提交；绑定请求时的快照和预览序号，预览变化后不显示旧下载结果；模拟延迟响应验证 |
| 窄窗口导航滚动条、悬停跳动 | 固定导航高度，隐藏导航纵向溢出，仅内容区滚动；取消导航按钮位移，标识当前页 |
| 设置复选框被通用输入框样式撑大 | 限定为 18×18，标签保持同一行；自动检查尺寸并截图 |
| 状态表单拥挤、操作列滚动后不可见 | 录入区两列字段，主次宽度调整；操作列固定在表格右侧，窄窗口实测可见并可点击 |
| 报告与可视化间距不一致 | 统一主内容边距，报告纸面去装饰蓝边与额外字距；1100 像素起地图与趋势保持双列，缩短地图高度 |

## 验收边界

没有宣称完成全部历史需求或正式交付验收。本轮不覆盖严格原 Word 模板逐页渲染、完整物理标定、所有多表/XLS/字段映射、备份恢复界面、岭澳/陆丰编码冲突、安装签名、干净 Windows 离线安装、共享服务器实连、长稳/压力测试和全量无障碍验收。三维现有综合测试通过，但最小窗口几何专项主要覆盖五个二维主界面。

表格可水平滚动以保留完整字段；界面固定操作列不表示所有字段可在窄屏同时完整展示。报告导出请求已发出后切换范围，不取消后端已开始的文件生成，只隔离旧结果，防止误认为新预览的文件。
