# 管状态批量删除与灵活识别

日期：2026-10-20。仅更新现有 Windows Electron 源码版，未打包、未新增网页产品。

同日后续修复：导入已取消预选基地/机组/大修要求，补齐无范围识别、持续反馈与重试。最新行为和无范围原文件验证见《维护表格自动识别导入修复_2026-10-20.md》，下文保留初版实现及当时验证记录。

## 本次变更

- 已维护记录增加管号/备注搜索、逐行勾选、筛选结果全选、所选数量和“删除所选”。支持基地、大修、机组、状态与搜索组合筛选；切换筛选或刷新会清除选择，搜索等待期间禁止删除。
- 删除先显示具体数量和大修范围，确认后只软删除所选维护记录；对应管恢复未维护，检测数据保留。每条记录写入状态修改历史，整批写入中文操作审计。
- 后端在单事务内校验所选键、状态、位移、备注、更新时间；任何记录已变动、重复或已删除时全部拒绝。写入失败整批回滚。
- 导入读取 xlsx/xls/xlsm/csv/docx，不要求列顺序与模板一致。支持管号/状态列、维护说明/备注列、横向通道块、历次大修矩阵、双层表头、含大修编号的文本及 Word 通道事件。
- 重复缺陷行的相同维护事件合并，并保留来源行；不同事件或身份冲突进入提醒，不静默覆盖。大修编号、机组、管号不跨范围重新分配。
- 备注自动保留状态摘要、原文、文件和表/行定位。提供“识别维护说明”与“生成备注”；识别说明先预览、填入编辑区，点击保存才写入。
- 导入预览支持逐条勾选、编辑备注、逐条选择方向、批量确认方向。单独提供未自动应用项。无符号距离仍需人工确认，不把磨损百分比、割管次数、NDD 或空白推断为维护状态。
- 同一段同时记载移位与堵管/换管时进入人工核查，不用单一状态静默丢弃另一处理事实。显式“状态”列优先于历史备注，避免回导时被备注内历史状态重分类。
- 预览采用固定头部和操作区、可滚动内容；小窗口及 renderer 150% 缩放下仍可取消/确认，长表格在自身范围横向滚动。
- 服务版本同步为 2026.10.20.3，桌面入口及本次资源版本更新；退出旧源码版后重新启动生效。

## 边界与 Git

- 识别是本地确定规则，可处理上述多种布局；不是对所有任意表格、扫描图片或旧版二进制Word格式的无条件识别承诺。无法确定的事实保留原文并提示人工核对。
- 本轮不改报告模板、不重建状态生命周期规则、不改原始资料及正式数据库。
- Git仅收录本轮功能文件与记录；`server.py`仅暂存服务版本及新接口路由，不混入已有官方管板映射修改。此前未跟踪的app.js和operation-log-viewer.js因本次修改而整文件纳入；外层旧目录删除、其他未跟踪资料及既有后端修改保留。
