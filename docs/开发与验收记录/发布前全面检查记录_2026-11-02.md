## 复跑入口

在当前版本目录执行，建议先设置独立输出目录：

```powershell
$env:THIMBLE_TEST_OUTPUT_ROOT='G:\codex-test-output\release-rerun'
npm run test:release
```

`test:release` 包含单元/静态、Python 和 26 组当前界面回归；`test:desktop` 只运行界面回归。首次会按固定版本准备 Electron 二进制，测试数据库使用隔离副本。

发布包验证使用 `THIMBLE_TEST_EXECUTABLE` 指定打包程序，并分别执行 `tests/release_lifecycle_desktop.mjs`、`tests/packaged_clean_start_desktop.mjs`；便携 EXE 使用 `tests/portable_launch_desktop.mjs`。
