# 第四批整改：跨组相同缺陷复核与统一统计

日期：2026-10-18。源码服务版本：2026.10.18.4。

**本批完成 F02/M19 对应的人工统计取舍闭环，不代表所有聊天与记忆需求已经全部验收。**

## 本批实施

1. 在本地 Electron 软件现有“报告与导出 → 数据质量与导入审计”中增加“跨组复核”页签，不新增独立网页产品或一级页面。逐组显示原始记录、数据组、磨损位置、幅值、相位、深度、显示类型、测量类型、通道和来源报告。
2. 支持指定一条统计代表、人工确认保留全部、撤销复核。保存操作人员、时间、依据、复核时全部原始成员和来源指纹；保留历史决定，不改写采集记录、不修改业务去重键。
3. 仅相同大修、机组、物理管、分析人员、不同数据组，且已报告缺陷信息一致时列为候选。比较项包括位置、测量通道、幅值、相位、深度、显示、测量类型、分析阶段、探头、通道 ID、距离及缺陷尺寸。NDD、结论不完整、不同分析人员/位置/尺寸等不自动折叠。候选始终需人工取舍，未复核默认全部计入，不凭数据组名称猜优先级。
4. 新增只读统计视图，工作台、二维/三维查询、概览、地图、分析、单管演变、历次对比及新旧报告输出统一使用有效统计记录。删除预览、导入、回滚和来源审计仍读取原始记录。
5. `raw=1` 继续表示不合并 NDD；`sources=1` 单独用于读取全部原始来源。概览增加 `source_findings`，与统计记录数分开。
6. 用 SQLite 触发器在相关大修/机组的记录发生实际增删改时使旧复核失效。采用保守的整个大修/机组范围失效策略，不只盯着代表记录；回滚后恢复原数据也不会悄悄恢复旧决定。再次复核需刷新；并发提交通过来源指纹、决定版本及有效状态拒绝过期请求。
7. 复核后清除工作台旧勾选并刷新数据；清除三维缓存中的旧勾选来源；报告快照立即失效重建。报告的来源清单保留被排除的原始记录并标明不参与统计，来源凭证包含复核历史；改动复核后无法导出旧快照。
8. 质量清单 Excel 增加“跨组复核历史”“跨组复核来源”两个工作表，历史成员按行输出，避免将整个来源数组塞进单个超长单元格。原有原始字段与导入审计保留。

## 使用与限制

入口：本地软件“报告与导出 → 数据质量与导入审计 → 跨组复核”。可按导入批次过滤，组内仍展示完整来源。来源变化后的失效历史保留，不再计作当前有效选择。

本轮修改源码，未重建安装包，未给既有业务库写入测试决定，未删除原始资料或无关文件。第三批记录中“仍未完成”第 1 项的统计复核实现已由本批承接；其他未完成项不默认关闭。
