# UI 统一优化

版本：2026.10.18.7。前序提交：`2169d8c`。本批只调整本地桌面 UI 样式、缓存版本与相应测试，不改变导入、统计、报告内容或三维物理规则。

## 调整

- 统一面板表头、轻边框和阴影，缩减视觉装饰；常用操作按钮取消悬停位移，避免操作目标跳动。
- 状态表单输入高度 36px，备注框支持垂直调整并限制高度，空列表留白统一。
- 设置页在 1280px 起将软件策略与严重度设置并排，服务器路径及数据库维护保持整行；较窄窗口恢复单列。色值和阈值输入统一对齐，保留全部现有控件。
- 报告页签、筛选器间距、折叠区圆角和键盘焦点统一。可视化指标字号、表头及按钮反馈与其他页面协调。
