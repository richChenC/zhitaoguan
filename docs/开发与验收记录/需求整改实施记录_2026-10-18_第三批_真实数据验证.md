## 真实数据验证

可重复执行的脚本：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/verify_real_data.py
node tests/real_data_desktop_verify.mjs tmp/real-data-20261018-215157
```

后端最终证据：`tmp/real-data-20261018-220928/evidence.json`。

桌面证据：`tmp/real-data-20261018-215157/desktop-evidence.json`，同目录保存地图、原始 CAD、紧凑桌面以及整体/单管十四视角截图。

1. 读取用户的 `测试数据/指套管数据1` 和 `测试数据/指套管数据2`。对其中 1310 个 ECT、RPT、SUM、SET、XLSX、DB 原文件计算前后 SHA-256，全部未变。
2. 测试使用新建隔离数据库。按测试规则每组选一份报告；候选与测试选取路径均写入证据。该规则只是自动测试输入，**不冒充人工确认，不作为最终业务报告版本**。第一套目录有 2 组多版本候选，第二套有 9 组，包含跨目录重复样本。
3. 第一套新增 193 条；第二套新增 472 条、拦截已存在的 193 条；两套合计有效记录 665 条。分别重复导入，新增均为 0。
4. 覆盖范围及记录数：F107 81、H209 123、H309 98、N109 87、Y108 70、Y307 67、Y406 139。目录中的其他组没有有效报告时，不生成虚构检测记录。
5. 读取 72 份真实 SET，全部识别为 ETerSetup 配置；其中包括扫描到的其他组件配置，**不代表将其他组件数据混入指套管检测库**。
6. 识别到 54 条三字符缺失记录，采用保留空值、待核查的方式导入，没有批量填成 WAR。重复导入会再次产生本批次提醒，证据中的问题条数是批次审计数，不能当作唯一缺陷数。
7. 七个范围各导出 DOCX、XLSX、CSV，共 21 份。XLSX 与 CSV 逐单元格/字段核对快照，DOCX 检查 ZIP 完整性和 XML 可解析；21 份来源凭证均与快照、来源、提醒和主文件哈希一致。**未完成 DOCX 渲染及逐页版面验收。**
8. 第一套真实数据完成文件夹 → 标准 Excel → 另一新建数据库的往返，193 条成功入库。这证明本轮样本可往返，不代表标准表已无损携带全部底层采样字段。
9. 使用 SQLite 只读连接备份现有业务库到测试目录，在副本连续初始化两次，记录数 5532 → 5532，原库哈希未变。在该副本上检查 59 组同基地同机组的历次对比，R/NI/待确认计数与输出行数一致。副本中既有台账记录的来源真实性未在本轮全部重新认证，不能把此项写成全部原始采集重新解析通过。
10. 真实 H209 123 条记录通过桌面接口范围检查；地图显示 10 个厂址标记并使用当前隔离库数量。整体与单管 14 个标准视角像素检查通过：整体采样 347–663 种颜色，单管 26–127 种。修复前单管前视图仅 8 种颜色、未通过检查，失败记录保留在上一轮测试目录中。

独立回归：70 项 Python 测试通过；39 个 ESM 脚本及桌面主脚本语法检查通过；`npm run test:desktop` 通过，含报告版本人工确认、状态审计、批次恢复、地图与三维画布验证。
