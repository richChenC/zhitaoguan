# 报告中心两种报告与表内编辑验证

日期：2026-10-22。软件：本地 Windows Electron 正式开发目录，未打包。

## 本轮修改

- 报告中心与模板目录 API 仅保留结果报告、历次大修对比报告；拒绝其他报告类型与模板 ID。历史源模板资料不删除。
- 直接双击预览表格单元格编辑。Enter 保存、Shift+Enter 换行、Esc 取消、失焦保存；侧栏仅记录草稿修改，支持撤销、单格还原、全部恢复。
- 同一预览支持 Word、Excel 导出；缩放 50%–150%、适宽、左右查看不改变报告数据或导出快照。
- 读取源段落及 run 的字体、字号、粗斜体、对齐、缩进、段落间距和行距。保持结果页宋体/仿宋_GB2312、对比表宋体/Arial及尾注 R 的 Times New Roman；不以通用表格重建 Word 源表式。
- 修复多段落文本导出 Excel 时丢失换行的问题，测试覆盖空白行、首尾空格、负数和通道连字符。
- 修复结果报告签名区角色标签被清空的问题，保留分析人员/级别、审核/级别、批准、业主；原人员和日期不沿用。
- 主导航与右侧设置、通知及连接状态分区；长请求超过 320ms 才显示忙碌指示，结束后稳定收起，减少短请求闪烁。沿用真实请求状态，不显示虚构百分比。
- 回收站 Escape 交互测试改为等待原生 dialog close 事件完成后再判断销毁，修复异步测试竞态。
