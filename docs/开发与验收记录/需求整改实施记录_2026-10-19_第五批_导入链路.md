# 第五批整改：Excel 导入链路（.xls / 多工作表 / 多文件 / 可编辑字段映射）

日期：2026-10-19。源码服务版本：2026.10.19.3（前端构建参数 `20261019-import-wizard`，`app.js`/`software-settings.js` 缓存参数 `20261019c`）。

**本批完成 F08 对应的导入链路缺口，不代表第四批记录中"仍需继续"的其他项已经关闭。**

## 背景与缺口

第四批记录列出的未完成项中包含"多文件多工作表 / XLS / 可编辑映射"。核对后确认三个具体缺口：

1. 只支持 `.xlsx/.xlsm`，现场大量历史台账是 WPS 生成的 `.xls`（如大亚湾 L3/L4.xls、宁德 4 台机组汇总），无法导入；
2. `import_excel_file` 只读第一张工作表，多工作表台账静默丢数据；
3. 表头稍不规范（列序变化、多余行列、中英混排）即整文件失败，且没有给操作人员修正入口。

## 本批实施

### 后端（`src/backend/server.py`，未新增任何第三方运行时依赖）

1. 新增 `src/backend/xls_reader.py`（约 530 行）：纯标准库 `.xls` 读取器，覆盖 OLE2 复合文档（DIFAT/FAT/Mini-FAT，mini 流 4096 字节阈值）与 BIFF8/BIFF5 记录（BOF/EOF/BOUNDSHEET/SST/LABELSST/LABEL/NUMBER/RK/MULRK/FORMULA/STRING/MULBLANK/DIMENSIONS），含 CONTINUE 分块按字符边界切分与 flags 字节重启、富文本/扩展字符串跳过。兼容 WPS 非标准写法：BOUNDSHEET 工作表名无长度前缀三种布局自适应、忽略伪造的 DIMENSIONS 范围、按实际单元格推导区域。接口对齐 openpyxl：`load_workbook(path, read_only=True, data_only=True)` 返回带 `worksheets/sheetnames/iter_rows` 的书对象。
2. `open_excel_workbook` 统一 `.xls`（stdlib）与 `.xlsx/.xlsm`（既有 vendored openpyxl）入口；`EXCEL_SUFFIXES` 扩展为三类。
3. `detect_sheet_mapping` 逐表识别表头行与字段-列映射。识别条件为**必须同时有"机组号""通道编号"和"幅值/三字码"之一**——导出的"管子汇总表""三字符缺失""跨组相同缺陷"等汇总/异常清单同样带有"机组号/通道编号"表头，若无测量列约束会被当作缺陷明细重复入库（该回归由单测捕获并修复）。
4. `import_excel_file` 重写：**导入全部可识别工作表**而非仅第一张；返回 `sheets` 明细（每张表的解析/新增/跳过/无效行）；支持 `mapping` 参数只导入指定表；每张表的映射写入新表 `import_excel_mappings`（批次、来源、表名、表头行、JSON 映射、时间），供审计追溯。`_normalize_mapping_override` 校验用户映射（表存在、表头行有效、列不越界、必填字段齐全）。
5. 新增 `POST /api/import-excel-inspect`：返回每张工作表的名称、行数、表头行、识别结果、字段映射和列清单，供映射向导使用。`POST /api/import-excel` 透传 `mapping`。

### 桌面端（Electron 壳 + 渲染层）

1. `src/desktop/main.cjs`：文件对话框过滤器加入 `xls`，开启 `multiSelections` 多选；新增 `select-excel-folder`（选择文件夹后递归扫描 ≤4 层、上限 500 个 Excel 文件，超限提示）；`SERVICE_VERSION` 与 URL 构建参数同步升级。
2. `src/desktop/preload.cjs`：`selectExcel` 返回路径数组（语义变更），新增 `selectExcelFolder` 返回 `{folder, files, truncated}`。
3. `src/desktop-ui/app.js`：导入对话框"第 2 步"改为多文件队列（芯片显示文件名/状态/进度，支持单文件移除与手动"映射"入口），新增"选择文件夹"按钮。逻辑实现位于 `software-settings.js`（该文件在 `app.js` 之后加载并接管导入对话框，处理器必须放在那里，此坑已用浏览器级验证捕获）。
4. `src/desktop-ui/software-settings.js`：队列渲染/去重/状态、字段映射向导（工作表切换、表头行、19 个字段×全部列的下拉对齐、必填与测量列校验、按映射导入）、队列顺序导入（逐文件先 inspect 再导入，识别失败自动弹向导，三字符缺失逐文件走既有确认对话框），完成后统一刷新工作台；导入 busy 态覆盖新按钮。
5. `src/desktop-ui/app.css`：新增文件队列芯片（进行中/完成/跳过/失败四态左边框）与映射向导网格样式，沿用既有 `--teal`/`--line` 令牌与向导头部、底部操作条风格。

## 使用与限制

入口：导入对话框"第 2 步：导入解析结果 Excel"。"选择 Excel"可多选；"选择文件夹"递归加载整个目录树的 Excel；队列逐文件导入，识别失败自动打开字段映射向导，也可点文件上"映射"手动指定工作表/表头行/列对应关系。`.xls`、`.xlsx`、`.xlsm` 均可。

本轮未重建安装包，未修改真实业务库，未改动冻结的后端接口语义（仅在既有 `/api/import-excel` 上增加可选 `mapping` 字段并新增 inspect 端点）。汇总表/异常清单类工作表按设计不参与缺陷明细导入；如确需导入此类表，应先在"报告与导出"流程中处理。
