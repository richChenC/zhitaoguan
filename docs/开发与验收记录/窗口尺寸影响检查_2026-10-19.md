# 窗口尺寸影响检查

版本：2026.10.19.1。日期：2026-10-19。前序提交：`96b111e`。

本批针对实际 Windows Electron 本地软件，不新增网页应用；调整桌面壳加载的本地界面和三维模型布局，不改变业务计算、导入规则和报告表格内容。

## 发现与修复

1. 三维主区域原先固定最小高度 680px：实际 1100×720、1280×720 窗口下，底部超出可用区域约 71px，1366×768 下超出约 23px。改为随可用视口高度分配，允许 iframe 收缩。
2. 基地/机组/大修选择原先悬浮在模型上方，高缩放下会挡住单管视图等按钮。改成独立第一行，模型占剩余区域，选择器可换行。
3. 短模型视口下工具面板和检测详情原先挤占/遮盖模型。现在模型在左，工具和详情在右分别滚动；详情保留至少 100 CSS px 的布局空间。极小有效视口需要滚动工具区，但不删除控件。
4. 三维尺寸观察在隐藏/最小化导致宽高为零时跳过渲染尺寸更新，避免相机纵横比无效；一般高度下详情起点跟随工具区实际高度。
5. 原有五列统计卡在小窗口高缩放时仍固定五列，文字挤成竖排。改为按卡片最小可读宽度自动换列；提示卡同步换列，数字不再被压缩。截图发现后追加文字宽度和卡片高度断言，不能仅用“没有横向溢出”判断可读。
6. 桌面、iframe、CSS 和脚本缓存版本同步更新，防止重启后仍载入旧布局。

## 验收边界

- 125% / 150% 是 Electron renderer zoom 压力测试，不是实际切换 Windows 系统 DPI，也未覆盖多显示器跨屏 DPI、远程桌面或全新 Windows 机器。
- 当前软件最小原生窗口为 1100×720；更小分辨率、任务栏占用后的可用工作区仍需在目标机器验收。
- 小窗口可以纵向滚动，不承诺全部内容同时出现在首屏。复杂宽表保留横向滚动，模型短窗右侧工具区也需要滚动。
- 本批不代表全部历史需求完成；严格 Word 逐页版式、完整物理标定、扩展导入映射、备份界面、机组代码冲突和安装包签名/离线验收仍沿用需求核对报告中的未完成状态。
