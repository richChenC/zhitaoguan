## 修正与保留失败

1. 管板旧测试仍要求把“维护资料不全”“暂无明确换管记录”等说明写入文件名，违背已接受的简洁命名要求。本轮修正测试：文件名保留类别、机组、大修和唯一标记；检查画布实际绘制文字，确认图片内仍有完整性及空数据说明，并保留非空像素验证。业务代码未因该旧断言而回退。
2. 综合台账发布版桌面下载连续三次出现中断：`DownloadItem` 从 `started` 进入 `progressing` 后报告 `interrupted`，接收字节为 0，目标文件不存在；后端生成的 Excel 存在且约 16 KB。Chromium NetLog 确认本地 HTTP 服务返回 200、`Content-Length` 正确、网络层收到了完整响应体。源码态先前两次通过，后续使用增强诊断再次中断；增加终态观察后，中断持续 60 秒仍未收到 `done`。原测试把 `updated` 的中断当成终态，已修正。C 盘空间已满可能是环境因素之一，但尚未证实；根因未确定，不能认为缺陷已修复，也不能断言只影响发布版。
3. 已完成的发布版专项中，状态维护、设置联动、本地角色权限、可视化、报告草稿、删除刷新、原生导出、备份恢复 8 组通过；台账下载这一组失败，不能将发布版全套标记为通过。
4. C 盘已满时，选择/导出超时，状态变化用例在复制临时数据库时失败。F 盘隔离环境中交互六组全部通过。原 C 盘失败结果保留，不计为通过。
5. 未清理已有目录和发布包。对本轮两组 C 盘证据目录尝试 NTFS 压缩后，未观察到可用空间恢复；后续回归和发布输出使用 F 盘。
6. 台账生成后不再提前提示“已导出”；桌面下载完成、取消和中断分别反馈。中断时提示检查空间及保存位置，真实 Electron 失败复测已确认提示显示，下载本身仍未修复。通知代码和单元测试只在源码中，r16 现有候选包未包含该修改。
