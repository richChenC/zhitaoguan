# 桌面 UI 统一优化与验证

日期：2026-10-20。对象：本地 Windows Electron 软件源码。本轮不执行安装包或便携包构建。

## 界面调整

- 工作台、可视化、结果中心、状态维护和设置共用中性背景、浅色边框、紧凑控件与一致的按钮层级。
- 导航保留左侧业务入口，使用细下划线标识当前页面；设置、通知保留图标及其下方的实际连接状态。
- 工作台将筛选字段与数据操作分成两行；延迟加载的删除、回收站入口也进入操作行，清空数据库靠右显示。
- 使用随软件提供的 Lucide SVG 图标，包含 ISC 许可，无运行时联网依赖。分页、刷新、关闭按钮保留中文无障碍名称和悬停提示。
- 可视化基地选项统一为紧凑选择控件，补充 Enter、空格键操作与选中状态；数据曲线和状态颜色继续用于业务区分。
- 状态维护的范围、批量操作与导入导出合为一个控制区。单管表单将取消、保存并排放置，保留移位方向和维护规则。
- 三维工具区、侧栏和外部筛选栏使用协调的深色表面，保持模型可选、画布不被工具区遮挡。
- 结果中心统一标签与导出操作；仅调整界面外框，不改变 Word/Excel 生成模板。修正旧样式覆盖原表预览页面宽度的问题，恢复 210 mm 页面宽度。
- 修复删除通知同时设置 top/bottom 后被拉成竖条、遮住筛选按钮的问题，改为底部紧凑提示，保留撤销和关闭。

## 后续修正：管板比例与导航

根据用户反馈的管位圆点变窄截图修正：

- 通用按钮的 `min-height:32px` 覆盖了管位的 26 px 高度，造成圆点纵向拉长。管位现使用独立尺寸、清零最小高度，直径按网格宽度等比调整。
- 原网格使用百分比宽高定位，外层横纵留白不一致，造成网格实际不为正方形。现单独固定网格 `aspect-ratio:1`，外层高度随网格自然展开，方向标识保留独立留白。
- 小于等于 960 px 的有效窗口中，管板单独占一行，详情置于下方。800×600 下网格为 484×484 px，圆点为 30×30 px。
- 导航改为图标配文字、浅色选中底与细边框，小窗口隐藏业务图标以优先显示导航文字。设置、通知和连接状态的位置保留。

专项测试增加 5 组尺寸/缩放、3 种管板模式的几何检查，逐个检查 50 个管位的等宽高、单元格等宽高、圆点不超过单元格、代表性窗口下直径不小于 20 px。原有报告导出与状态保存测试继续通过。
