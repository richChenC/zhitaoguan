# 移位距离与设置联动（2026-11-03 修订）

用户进一步明确：识别、导入和状态保存均应跟随设置中的“无符号移位默认方向”。初始默认值为正向，但不在代码中固定方向。

- 设置为正向：`移位42mm`、`割管移位42mm`、`位移距离42mm` 自动保存为 `shifted`、`offset_mm=42`，无需逐条核对方向。
- 设置为负向：相同无符号说明自动使用 `offset_mm=-42`，同样无需逐条核对方向。
- 设置为留待核对：保留 `unsigned_offset_mm=42`、`offset_mm=None`；检测备注进入待核对清单，维护表允许保留未确认方向。
- 明确的正负号及导出的有符号位移列优先于默认设置；`移位+42mm` 始终为 `+42`，`移位-42mm` 始终为 `-42`。
- 无距离时保留移位事实，距离留空，不按零距离参与位置换算。
- 距离冲突、不同管号或大修、历史生效时间不明、已有维护记录等核对规则保持有效。
- 检测数据导入中的明确维护备注自动写入状态；独立维护表仍使用原有整批预览及保存流程，不增加方向确认步骤。

实现覆盖普通维护说明、历史参考表、检测导入和编辑备注识别、旧版维护事件工作表、批量保存和单管保存。旧格式无符号距离在写入前校验，再按当前设置处理；负数、非数值和越界的无符号字段仍拒绝保存。切换设置不会重算已保存的历史位移；旧记录查询、删除及审计快照保留原值。

新增迁移 `004_state_direction_preference`，将方向保存到当前本地数据库的 `state_preferences` 表，随备份恢复。第一次打开时仅迁移一次浏览器已有设置；之后以数据库值为准，避免新窗口或旧缓存覆盖。设置页面、状态维护快捷选项、跨窗口更新及恢复默认统一通过本地接口保存，业务写入等待设置保存完成。保存失败会提示并恢复实际设置。逐条方向调整仅作用于当前预览行。

设置修改遵循本地账户权限：管理员、数据编辑员和导入员可修改；只读账户不能修改。每次实际修改记录操作人与前后值。登录图标保持原软件图标，本轮没有打包，也未使用真实业务数据库做写入测试。
