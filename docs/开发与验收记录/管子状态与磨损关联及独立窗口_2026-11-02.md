# 管子状态与磨损关联及独立窗口

## 本次需求

- 管号与通道号对应当前具体机组的管子，不能跨基地、跨机组合并同号管。
- 奇数机组和偶数机组分别使用对应的管号到管板坐标映射。
- 单管纵向图关联维护历史和磨损深度，准确反映堵管、移位、换管及复合处理。
- 各可视化图表能够在独立小窗口中展开，并同时比较。

## 已实现口径

1. 物理身份使用“基地 / 机组 / 管号”，坐标调用系统已有奇偶映射。
2. 每次大修仍保留原始最大有效检测深度。明确 NDD 为 0；无数据、未量化不补零。
3. 默认显示在役管深度。换管结束旧代管曲线，建立新代管 0 基线，不跨代计算突变。
4. 可切换查看原始检测深度。换管大修的原始报告数值不会覆盖为 0；不推断该次检测与换管的实际先后。
5. 移位不重置磨损，也不因移位方向待核对而切断深度变化；方向问题仍显示维护核对提醒。
6. 堵管、移位等有效状态读取同一物理管的维护历史，支持叠加；后续单次“正常”不自动解除历史堵管，明确换管结束旧管状态。
7. 维护事件与换管先后不明时显示核对提醒，不擅自确认新管基线。维护无检测的轮次保留状态信息；缺失检测不视为 NDD。
8. 历次检测演变导出的可视化摘要使用原始检测口径，保留报告深度。

## 独立窗口

- 图表标题处新增“在独立窗口中对比”图标。
- 支持 12 个面板：群厂趋势、P 位趋势、磨损集中位置、管板分布、单管纵向、单次深度直方图、按管号散点、覆盖核查、深度分级、位置频次、机组对照、变化与状态。
- 可同时打开多个窗口，保留打开时的筛选和选择，各窗口独立操作、缩放和关闭。
- 单次检查图保留机组与大修选择，纵向图保留机组、选管与深度口径选择。
- 主界面数据变更通过本地消息通知图表窗口刷新；不把窗口的筛选更改写回主界面。
- 启动读取失败显示重试入口，窗口内提供刷新数据按钮。

## 第二轮修复与回归

### 修复项

- 管板独立窗口携带当前选中的管子，主窗口后续选择不会改动该窗口的选管。
- 纵向图切换机组、深度口径或阈值时，加载期间清除旧图例与旧明细，禁用全选、清空，阻止导出正在加载的图表；延迟返回的旧机组响应不能覆盖新选择。
- 纵向 PNG 导出补上已选管号与坐标图例，并标注具体机组、深度口径和选管范围；未选择管子时先提示选择。
- 无有效深度的管子显示“历史最大未量化”；最新大修深度缺失时明确显示缺失，不用旧轮次的数值冒充最新结果。
- 磨损分级阈值变更通过统一事件同步刷新直方图、趋势、散点和风险图，避免设置页与已打开图表显示不一致。
- 窗口关闭前主动释放 `BroadcastChannel`，避免重复打开/关闭图表后产生过期消息和资源残留。
