# 可视化布局与批量管状态维护

日期：2026-10-20。目标为现有 Windows Electron 本地软件，不新增网页产品。

## 本批实现

- 工作台左右面板等高；左侧检测表格伸展填满剩余高度，分页保留底部，不再留分页下方大块空白。窄窗口保留滚动。
- 去除六个主页面重复的导航介绍标题，不删除三维模型功能及其筛选；去除 TH 标记，操作通知改为简洁文字入口。
- 地图和管板放大，增加全屏入口。地图全屏覆盖旧样式的最大宽度限制；刷新计数时保留全屏容器，修正缩放、拖拽的 SVG 坐标换算。珠三角标签引线分开，大亚湾/岭澳仍指向同一地理点。
- 状态处理增加“全部设为正常”（需要输入“全部正常”二次确认）和“一键补齐正常”（保留所有已有维护记录）。作用范围是所选基地、机组、大修的 50 根管。
- 支持 Excel / CSV 维护表导入，先识别预览，再确认写入；支持导出当前 50 根管状态和维护模板，保留备注与有符号位移。
- 空白状态跳过，不从检测磨损、NDD 等推断正常。重复键、无效管号、非整数机组/管号、无效位移先校验。批量写入使用单事务，异常全部回滚，保留每条状态历史。
- 前端资源版本和桌面/后端服务版本同步更新。需退出旧软件后重启源码版；本批未重新构建安装包。
