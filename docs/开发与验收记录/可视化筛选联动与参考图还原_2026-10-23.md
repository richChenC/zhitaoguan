# 可视化筛选联动与参考图还原

日期：2026-10-23。实施范围：当前 Electron 本地桌面软件的数据可视化、基地名称兼容及相关测试。没有打包，没有向正式数据库写入测试数据。

## 需求与实现

| 用户要求 | 实现及边界 |
| --- | --- |
| 折叠卡片不自动改变 | 数据核查、大修核对、单管明细和历史通过稳定键保存展开状态。刷新、筛选、管号和指标切换时保持用户操作；当前会话有效，重启默认收起。 |
| 右侧随选管更新 | 点击或键盘选择管格立即更新详情、距离、原文备注、独立来源及历史。悬停显示提示，不覆盖已选管。 |
| 参考三张图 | 提供多机组磨损趋势、P位分层与总量、灰底绿格管板及黄色/红色换管框。支持全屏。图中数值使用当前数据库；参考图来自不同数据范围，曲线及数值不能宣称逐像素相同。 |
| 取消奇偶标识 | 删除外圈和奇偶文字，保留实际管号到堆芯位置的映射。实测偶数机组通道1为B5，奇数机组为L11。 |
| 简化筛选 | 基地按钮直接组合选择，统一机组和大修下拉，不显示单选/多选模式或重复检测范围。切换基地清除失效下级选项。 |
| 选项和数据实时变化 | 发起请求时更新筛选状态，返回时校验请求序号，较早响应不能覆盖新范围；加载时旧图弱化并禁止操作，显示进度反馈。 |
| P位可选全部机组 | P位独立选择器提供全部机组，按每台机组自身的大修轮次汇总；参与台数可能不同，不视作同一日期。 |
| 机组概述排序 | 按基地分组、机组编号自然排序，避免LF陆丰与L岭澳混淆。 |
| 空范围不占大空间 | 无有效数据时使用紧凑空状态，不生成空白SVG；首次无数据也正确创建右侧详情。 |
| 接入新基地 | P显示惠州，兼容太平岭旧资料；LF为陆丰、C为苍南。后端解析、状态识别与导出名称、前端筛选使用对应代号；已测无数据及有数据两种范围。 |
| 分析主次 | 总览优先覆盖与缺口、机组概述和P位构成；单管页聚焦管板与详情；趋势页比较大修数据。增加按真实堆芯位置汇总的通道磨损次数分布。 |

## 原资料和统计含义

参考资料：`指套管磨损统计分析结果.pptx`（15页）、`4月份答辩报告(指套管检查).ppt`（33页）、防城港2号机组磨损速率原因分析报告及三张参考图片。资料只读；演示文稿图像核对位于 `tmp/viz-reference-20261023/`。

- 趋势及P位总量为有效WAR报告深度之和，单位为百分点，不是单管深度、磨损速率或匹配缺陷增量。
- P1至P5为原报告结构位置，数据库中的P6和未解析位置单列，不强塞进P1至P5。
- 有效零值、明确NDD、结论不完整、无记录和WAR深度未量化分别处理。缺失不补零；部分合计标空心点。
- 次数图按同机组、同大修、同通道去重，取有效WAR最大深度，与阈值严格比较；不同机组通过真实堆芯坐标汇总。20/40/65仅作分析阈值，不当作维修判据。
- 换管次数仅来自截至所示大修的明确换管记录；割管移位不算换管，没有换管记录不等于从未换管。
- 备注保留原文与换行，来源独立显示；方向未明的移位距离明确注明待确认。
