# 窗口布局与操作优化

日期：2026-10-20。本批继续修改现有 Electron 软件，不重建业务系统，不变更检测统计口径。

## 布局调整

- 最小原生窗口由 1100×720 调整为 800×600；短窗口允许主区域纵向滚动，不要求全部内容挤在首屏。
- 三维视图的模型、工具和详情分区，宽窗口及低高度视口使用左右布局；窄而高的视口使用上下布局。保留模型最低可用高度，工具和详情可独立滚动，不再覆盖场景。
- 设置输入框限制在自身网格内，长路径、规则备注和说明允许换行；极窄视口表单改为单列。
- 备份摘要、列表、恢复确认弹窗自适应；恢复弹窗正文可滚动，标题和底部确认区保持可达。
- 报告表头在窄视口切换为两列或单列，选项和标题可换行；状态维护的窄屏管号网格改为五列。
- 删除弹窗正文允许滚动，头部和底部不被压缩；宽表格仍使用自身横向滚动，避免压扁数据列。
- 更新桌面入口、相关脚本和样式缓存版本。

## 操作调整

- 建立对比规则前校验非空名称和容差范围；提交中锁定按钮，失败保留输入，可再次提交。
- 规则建立成功通知分析和报告模块刷新失效结果。
- 备份过程中同时锁定默认目录和指定目录按钮，含目录选择阶段；取消或失败后恢复。
- 恢复备份先展示校验状态，仅在备份存在且校验结果有效时开放确认勾选。
- 恢复写入期间禁止取消和 Escape 关闭；失败保留弹窗以便重试。关闭后忽略迟到校验响应并恢复焦点。
- 恢复成功通知相关数据视图刷新；校验等待、通过和失败分别使用中性、绿色和红色反馈。

## 验收边界

- 测试的 125% / 150% 是 Electron renderer zoom，不代表真实 Windows 系统 DPI 或多显示器跨屏已验收。
- 小窗口采用滚动保留可用尺寸，不承诺所有信息同时显示；右侧工具栏、详情、长表格各有合理滚动。
- 这是上述界面与主操作流程的专项优化，不表示全部功能、全部数据排列和每个可能窗口尺寸均已验收。
- 未重新构建安装版或便携版；关闭源码版窗口后重新运行项目根目录的 `启动本地指套管软件.cmd` 加载本批改动。
- 原始资料、正式业务数据库和既有未提交改动保留原状，本批未创建 Git 提交。
