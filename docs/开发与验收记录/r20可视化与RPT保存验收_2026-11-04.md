## 本轮修复

- RPT 转换结果区分“Excel 已生成”和“Excel 已保存”，点击文件名使用桌面原生另存为。

- 新文件名采用 `TH_RPT检测数据_范围_时间_唯一标记.xlsx`，避免将转换结果称为检查表。
- 保存结果自动换行，失败信息加粗，连续点击只发起一次保存。
- Python 测试同时隔离数据库、数据目录、Excel 和报告目录，避免导出落在空间不足的本机目录。
- 综合 UI 回归补齐报告的原生保存操作，并逐字节核对保存文件与生成文件。
