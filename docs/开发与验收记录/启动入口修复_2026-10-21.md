# 本地 Windows 软件启动入口修复

日期：2026-10-21。

## 原因

从项目根目录运行“启动本地指套管软件.cmd”时，Windows cmd 将 UTF-8 中文路径按其他编码解析；脚本同时使用 LF 换行，导致部分命令被截断。实测出现“不是内部或外部命令”，未进入软件内层启动脚本。直接运行软件目录内的入口可以正常启动。

## 修复

- 外层入口在解析中文路径前切换到 UTF-8，使用 Windows CRLF 换行。
- 启动后透传内层脚本的退出码，避免失败时返回成功。
- 项目根目录增加 `*.cmd text eol=crlf`，防止 Git 检出后再次改变批处理换行。
- 本次不修改业务识别逻辑、数据文件或用户原始文档，不打包软件。

## 验证

- `tests/test_windows_launcher.py`：隔离目录测试通过，覆盖 GBK（936）、UTF-8（65001）、含中文和空格的目录、从其他工作目录运行以及成功/失败退出码，共4种组合。
- 从 `C:\Users\22234` 调用修复后的根目录入口成功，退出码为0，无乱码报错。
- 本地 Electron 主窗口已打开，窗口标题正确，Windows 显示 `Responding=True`。
- 本地服务健康接口正常，版本为 `2026.10.21.1`，连接现有数据库。
