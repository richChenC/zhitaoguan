# 导入异常处理

## 查看与处理

- 导入结果保留成功、部分完成和失败批次的详情入口。
- 详情区分错误与提醒，展示文件、工作表、行号、字段及处理建议。
- 明细每页 50 项，总数采用后台完整计数，可导出完整审计 Excel。
- 历史批次在“设置 → 导入 → 数据质量与导入审计”中查询。
- 队列重试仅处理未完成文件；已完成文件中的无效行需要修正来源文件后重新添加，重复记录由现有导入规则跳过。
- 误导入先核对批次再回滚；回滚不撤销管状态，管状态应在状态处理界面另行核对。
- 批次创建前的文件校验失败可能没有批次编号，应结合文件提示和本地服务日志排查；本次未将预检改为写入数据库。
