# 管状态同义词与无距离移位识别

日期：2026-10-21。适用本地 Windows Electron 软件；本次未打包。

## 本次规则

| 原始表达 | 处理 |
| --- | --- |
| 割管移位、切管移位、移位、位移 | 移位；距离可以空白 |
| 封堵、封管、堵管、安装堵头 | 堵管 |
| 更换、换管、替换 | 换管 |
| 移位42mm、切除4.2厘米 | 保留42mm距离；方向未注明时不填正负号 |
| 移位+42mm、移位-42mm | 保留明确的有符号毫米值 |
| 移位50%（切除41mm） | 移位；距离41mm；百分比不作为距离 |
| 4、5、6封堵 | 分别生成4、5、6号管的堵管状态 |
| 未割管移位、未封堵、拟封堵、打开堵头 | 不自动写为已执行的维护状态 |
| 同时记载移位与封堵、多个不同处理事件 | 原文保留，提示人工核对 |

备注字符串不做删改，包含首尾空格、全角字符、制表符和CRLF。解析只使用规范化副本。来源独立保存，工作台自动识别时记录实际来源列名。

## 数据与对比

通过可追加的字段区分未知距离与明确的零位移，兼容旧数据库的有符号位移。查询、编辑、Excel/Word导出再导入均保留该区别。原表仅写状态也可以保存；有数值但无方向时另列保存数值。

距离或方向未知的移位不自动参与位置换算，历次对比显示待确认。旧版维护批次的撤销和恢复兼容新增字段，原始审计快照不改写。
