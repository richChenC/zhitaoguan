# 界面与交互优化记录

本批修改现有 Electron 软件，覆盖六个主工作区及共用反馈、删除和审计流程。

## 实施范围

| 工作区 | 调整 |
| --- | --- |
| 检测数据工作台 | 筛选标签、信息层级、选择数量、删除按钮状态、键盘选行、页面滚动位置记忆 |
| 三维缺陷模型 | 明示独立范围与工作台范围，增加手动同步；窄窗口将工具、场景和详情分开，避免覆盖模型 |
| 数据分析 | 统一布局、加载状态、错误与重试，保留原有图表和业务统计口径 |
| 结果与报告 | 表头编辑表单、预览忙碌状态、导出按钮忙碌锁、成功反馈、过期响应隔离 |
| 管状态维护 | 保存状态与确认反馈、键盘可达性、紧凑布局；验证创建、修改、筛选和撤销 |
| 软件设置 | 统一表单与开关尺寸，增加真实操作审计入口 |

共用反馈包括成功、警告和错误通知、会话通知历史、可关闭通知、弹窗内可操作通知、真实请求活动指示及文字确认。导入等待使用不确定进度，不伪造百分比。

## 删除和回收站

- 删除范围预览失败时阻止进入确认，不以空预览代替服务错误。
- 删除确认改用原生模态对话框，支持 Escape、焦点恢复和键盘操作。
- 永久删除进入文字确认；回收站永久删除和全库清空分别要求输入对应文字。
- 提交期间锁定控件，失败保留当前内容并支持重试；撤销失败恢复按钮可再次使用。
- 修复二次确认返回时旧事件处理器残留的问题，关闭时清理倒计时。
- 移除未实现的“30 天后自动清理”提示。
- 回收站使用真实分页、过期响应保护、空态与失败重试；来源字段按文本显示。
- 审计直接查询 `operation_logs`，与回收站现有批次独立，按时间和编号稳定排序。
