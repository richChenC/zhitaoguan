# 离线资料工具

这里保留提取期和维护期的工具，不属于桌面软件启动流程。

- `_paths.py`：统一解析本版本内部的源码、参考资料、原始验证数据位置。
- `_extract_ledger.py`、`_extract_real.py`：从业务参考资料生成桌面内置数据资源。仅在复核来源和规则后人工运行。
- `_build_import_xlsx.py`：生成标准台账到 `output/ledgers/`，不覆盖原始资料。
- `_import_ledger_db.py`：历史全量替换脚本，会清空检测记录后重新导入；不是日常“追加导入”入口，严禁在无备份的业务库上直接执行。验证时必须显式设置隔离的 `THIMBLE_DB_PATH`。

日常业务导入、状态维护和报告导出使用桌面软件中的相应操作。历史维护脚本与实时业务流程分开保留，避免误把一次性迁移操作当成软件功能。
