# 在役检查系统-指套管数据管理工具（Qt 主版本）

`08_Qt移植版/` 是项目唯一主版本，后续软件功能、界面、修复和测试均以此目录为准。`01_当前软件/软件正式版_20261021/` 是旧 Electron 版，只用于对照，不会自动同步或合并代码。

## 日常启动

从项目根目录双击 `启动Qt主版本.cmd`。启动链为：

```text
项目根目录启动脚本
  -> 08_Qt移植版/启动正式版.cmd
  -> 08_Qt移植版/启动Qt版.cmd
  -> .venv-qt/Scripts/pythonw.exe -m qt_shell.main
```

`启动Qt版-调试.cmd` 使用同一 Qt 环境并显示退出信息，供本机排查启动问题。Qt 版使用本地 PySide6/Qt WebEngine 桌面壳承载现有界面，并启动配套本地数据服务。

## 数据与隔离

Qt 版数据库和运行状态保存在 `user-data/`。它与旧 Electron 版用户数据 `06_软件运行数据/用户运行数据/` 独立；切换启动入口不会迁移、覆盖或合并数据库。若需继续使用旧版最新记录，应先备份，再单独执行迁移和数据核验。

运行使用本机数据服务和 SQLite，不要求将软件作为独立网站发布。测试必须使用隔离副本，不要对正式业务库执行测试写入。

## 发布包边界

安装包是纯软件包，只包含 Qt 冻结桌面程序、冻结后端程序、用户手册、报告模板和应用图标。`user-data/`、数据库、运行日志、导出文件、测试与验证资料、源码、开发记录和构建目录均不会进入安装包；安装后数据库和日志仍按安装向导选择的位置单独创建。

## 开发与测试

- Qt 桌面壳：`qt_shell/`
- 业务源码：`src/backend/`、`src/desktop-ui/`；`src/desktop/` 为原桌面实现基线
- 随附资源和依赖：`assets/`、`.vendor/`；本机 Qt 环境：`.venv-qt/`
- 配置：`config/`；开发、构建和验证脚本：`scripts/`
- 测试：`tests/`；Qt 专项验证：`tests/qt/`。其他桌面测试包含旧版基线，不应直接视为 Qt 测试
- 文档：`docs/`；核心架构、规则和需求文档在根层，`docs/开发与验收记录/` 保存过程记录，`docs/使用手册/` 保存手册
- 验证证据：`验证/01_启动与环境/`、`验证/02_基线与对拍/`、`验证/03_专项报告/`、`验证/04_界面截图/`、`验证/05_对比结果/`
- 构建产物和打包材料：`build/`、`打包/`；其中后端程序可能被运行或打包依赖，不要按目录名直接删除
- `tmp/` 是部分旧版验证脚本的默认输出位置；新测试应使用下述项目根目录位置
- 启动入口模板：`scripts/start-current-version.cmd`；日常使用项目根目录的 `启动Qt主版本.cmd`

使用本目录的 Qt Python 环境运行测试：

```powershell
.\.venv-qt\Scripts\python.exe -m unittest discover -s tests -p test_windows_launcher.py -v
.\.venv-qt\Scripts\python.exe -m unittest discover -s tests\qt -p test_backend_service.py -v
```

所有测试生成的数据库、导出、缓存和截图统一放在项目根目录的 `05_测试与验证/03_自动化临时产物/`，测试结束后按项目约定清理可重建产物并保留必要结论。

`scripts/cleanup-test-artifacts.ps1` 默认只盘点并生成清单，使用 `-Apply` 才删除符合条件的文件。执行前应检查清单和运行中的程序；它还会检查指定的历史测试沙盒，不会清理正式用户数据。不要把旧验证材料、业务导出或数据库仅凭名称当作临时文件删除。

## 目录速查

| 目录 | 用途 | 备注 |
| --- | --- | --- |
| `src/` | 前端、后端和工具源码 | 运行时核心，不放测试产物 |
| `qt_shell/` | PySide6/Qt WebEngine 桌面壳 | Qt 启动实现 |
| `tests/` | 单元测试、桌面回归和 Qt 验证脚本 | 测试输出不写回源码目录 |
| `scripts/` | 启动、构建、打包和维护脚本 | 构建缓存统一放 `build/` |
| `assets/`、`.vendor/` | 应用资源和构建依赖 | 发布时仅取报告模板和应用图标 |
| `config/` | 本地配置模板 | 不保存正式用户数据库 |
| `build/`、`打包/` | 可重建构建和发布材料 | 由构建脚本使用 |
| `user-data/` | Qt 正式运行数据库、日志、导出和缓存 | 业务数据，禁止测试清理 |
| `tmp/` | 旧版脚本兼容输出目录 | 新测试请使用项目根目录测试临时产物 |
